# 作品信息采集与归档

## 使用流程

左侧「新建任务 / 任务 / 设置」是一级入口。页头按钮可将桌面侧栏完全隐藏或重新显示；手机上使用抽屉导航。设置按「下载、书目来源、AI 模型、字段、识别规则、连接、安全」分 Tab，地址栏片段可直接定位，例如 `/settings#connections`。同页切换保留未保存的普通输入；保存仅作用于当前区块。

新建任务先选择 Telegraph 链接或上传压缩包。作品信息先显示常用字段，简介与分类等可选字段按需展开；「采集信息」可切换截图识别和书目搜索，当前截图、校对文字和作品草稿会保留。桌面上作品信息位于左侧、采集信息位于右侧；手机上依次显示来源、作品信息、采集信息和提交操作。

在「新建任务」粘贴同一作品的介绍截图，或选择多张图片。最多 10 张；每张 10 MiB、整组 50 MiB、每图 1200 万像素且边长不超过 8192。简中、繁中、日语和英语识别在本机浏览器执行。先选择必要语言，再校对每张文字；顺序可以调整，失败图片可以单独重试。采用新识别原文需要明确操作，重试不会覆盖已校对文字。

「设置 → 识别规则」保存标签到元数据字段的有限映射。规则支持标签值、后续段落和话题标签列表；不执行正则、脚本或远程请求。规则生成候选后仍需选择采用。

AI 为可选步骤。在设置保存兼容接口地址和凭据，读取模型列表并选择模型。使用时确认具体目标、字段和本次发送文字；图片不会上传到 AI。OCR、校对文字和发送预览只在当前页面内存中。已采用的字段及其来源进入任务快照。

当前文本提取的精确预算适配器支持固定 llama.cpp `11fe02151f79c41d0d4af7da708755d73b9c0da6` 协议，包括此前选定的 MiniCPM5-2B Q4 部署方式。它核对模型、模板及上下文，调用同一目标的 `/apply-template` 和 `/tokenize`，再把已预算 token 传入 `/completion`。模型发现与中性连接测试通过，不代表提取预算能力通过；不满足此协议的服务明确返回不支持。不会静默截断、自动切换模型或扩大上下文。RackNerd 试验地址能否被应用容器实际访问需单独验证，本功能不创建网络隧道。

## 公开书目源

设置可分别启用 MangaBaka、MangaUpdates 和 Bangumi，排序并保存支持的选项；Bangumi 可以配置独立 bearer 授权。检索只向勾选的来源发送本次关键词。结果显示来源、公开链接和署名信息；选择详情后逐项核对采用。单个来源失败不丢弃其他来源结果。

可扩展字段不限定为旧七项。自定义字段需先注册，再显式映射兼容的来源字段。来源不会自动创建字段。BL/男同题材与成人同人作品的实际覆盖取决于来源收录及访问权限，空结果不能证明作品不存在。中性公开搜索测试与真实成人资料覆盖分别记录。

## Telegram 登录与下载

生产镜像内置官方 tdl 0.20.4 和使用相同依赖的认证 helper。在「设置 → 连接」发起 Telegram 登录，用手机扫码确认。若需要两步验证，在该面板输入；密码只通过受保护请求和进程私有标准输入传递。离开连接 Tab 清理页面的二维码、密码和事件连接；返回重新读取账号状态。只有 helper 明确授权成功且新进程恢复会话验证通过后才启用候选账号。旧 `/telegram` 地址跳转到此 Tab。

新建任务仅提供 Telegraph 链接与上传压缩包。按用户调整，Telegram 消息下载来源已从页面移除；账号管理与已有任务记录保留。已有 Telegram 任务冻结的账号身份及版本保持不变，换账号后不会由新账号接管；登录与验证仍遵循单账号锁和进程清理契约。

部署配置：

| 配置 | 默认值/用途 |
| --- | --- |
| `TELEGRAM_ENABLED` | Compose 默认 true；直接运行 Go 默认 false |
| `TELEGRAM_MAX_SOURCE_BYTES` | 524288000，只允许调低至正整数 |
| `TELEGRAM_PRIVATE_ROOT` | `/app/telegram-private`，API/worker 共用私密会话目录 |
| `TELEGRAM_HELPER_PATH` / `TELEGRAM_TDL_PATH` | 镜像内 `/app/tdl-auth-helper` / `/app/tdl` |
| `SOURCE_RETENTION_PATH` | `/app/source-retention`，原件与元数据副本 |

Compose 使用独立持久卷保存两类私密数据，目录权限为 0700，文件为 0600。若覆盖 `APP_UID/APP_GID`，挂载目录必须预先由该用户拥有。备份数据库、会话卷、原件保留卷以及独立的来源设置加密主密钥；不要把这些目录放进静态目录或构建上下文。恢复时保持数据库与对应会话/保留卷一致。首版 Telegram 网络访问使用服务器直连。

## ComicInfo 与原件保留

上传支持 ZIP/CBZ/RAR/7Z，浏览器上限仍为 64 MiB。归档以固定 ComicInfo 2.1 draft profile 导出；自然顺序的图片使用唯一四位页名，核对字节、哈希与 CRC。缺省字段保留原信息，明确清空才删除，实际页数由归档生成；提交快照与最终文档分别保存。

原归档、无法映射的元数据、竞争格式与扩展字段副本保存在私密保留目录，按任务和执行代际隔离并登记哈希。损坏或多个 ComicInfo 会停止发布；无法确定的 Pages 映射会给出提示并保留原数据。来源、凭据和 OCR 原文不会写入公开 CBZ。成功登记持久副本后才清理临时来源；保留副本目前没有自动到期删除策略。

实际 Komga/Kavita 导入效果与离线 XSD 校验是不同验收项，见 Trellis 批次验证记录。升级采用前向数据库迁移；回退程序版本时不要删除元数据、凭据和保留表或卷。
