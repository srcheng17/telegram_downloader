# 管理 Komga 中已有作品的元数据

状态：in_progress。2026-10-05 用户要求在 Komga 作品列表中选择文件并手工编辑元数据，随后明确选择首版**写回 CBZ 内的 ComicInfo**。本任务是媒体工作区父计划的独立子任务；不把新建任务时生成 ComicInfo 视为存量编辑已完成。验证只使用隔离测试书库，不修改用户实际漫画文件。

## 目标与用户价值

管理员在应用的「作品库」入口浏览已配置 Komga 书库中的作品，选择一本 CBZ，核对并手动修改可映射的元数据。明确保存后，改动进入原 CBZ 的根目录 `ComicInfo.xml`，并在 Komga 重新分析后可见；漫画页面、其他归档条目和原件恢复路径得到保护。无需重新下载或上传作品。

## 已确认背景与决定

- 当前项目只能把成功 CBZ 复制进 `KOMGA_LIBRARY_ROOT`，没有 Komga 书籍列表/API 凭据或存量文件写回。现有 ComicInfo 打包器会重命名和重排图片，且拒绝覆盖已有产物，不能作为存量编辑器。见[项目现状](research/current-project-surface.md)与[无损写回调研](research/safe-cbz-writeback.md)。
- Komga 1.28.1 官方 API 可按书库分页列出 book、读取详情，并以单书 `analyze` 异步重新读取改写后的归档；元数据 PATCH 只修改 Komga 自身数据库，**不会**写回 ComicInfo。见[官方接口调研](research/komga-official-api.md)。
- Komga 从 ComicInfo 导入空值时不会清除已有数据库值；部分 book 字段可通过补充 PATCH 清空，另一些字段不能清空。PATCH 只能作为**CBZ 写回之后的投影同步步骤**，绝不能替代文件保存。详见[字段语义调研](research/komga-field-semantics.md)。
- 首版保存目标是 CBZ 文件内的 ComicInfo；Komga 的显示结果通过分析/刷新同步并独立验证，不用数据库 PATCH 假装文件已改。列表按“管理 Komga 中已有文件”覆盖配置允许的书库，编辑对象为当前 book；系列全局元数据不是单本编辑的隐式副作用。
- 首版只写 `.cbz`。Komga 中的其他格式可列出和查看基本信息，但编辑入口说明不支持写回；没有共享写入挂载的书库同样只读。用户选择的可扩展字段中，只有具备可靠 ComicInfo 2.1 映射的字段可在此流程保存到文件；未映射字段明确标示，不伪称随 CBZ 迁移。

## 需求

| ID | 可观察行为 |
| --- | --- |
| K1 | 「作品库」按允许的 Komga 书库筛选、搜索、分页列出已有 book；显示标题、系列、文件名/类型及可编辑状态，空列表、Komga 不可达和权限不足有清楚反馈，不一次加载全库。 |
| K2 | 选择 book 后读取 Komga 详情和实际 CBZ 的唯一根 ComicInfo；显示原值、未填写、明确清空与保持不变。编辑与异步列表刷新隔离，未保存草稿不被覆盖；保存前展示字段差异和不能写入 ComicInfo 的字段。 |
| K3 | 字段按 ComicInfo 与 Komga 导入/清空能力列白名单：只有可安全映射且有可核对 Komga **单书投影和锁状态**的 set 可编辑；系列级及无单书投影字段首版只读。book 的 `summary`、`releaseDate`、`authors`、`tags`、`isbn`、`links` 可显式 clear，但库启用条码 ISBN 导入时禁止清空 ISBN，`title`/`number`/`numberSort` 不提供 clear；`page_count` 不能作为普通手工字段修改，旧值与实际图片数不符时须单独确认修正。集合/readlist 添加语义字段不当普通 set/clear。保留未改标准值；未知 XML 扩展、异常 Pages、竞争元数据或非标准 ZIP 结构无法保真时拒写。内部自定义字段不虚报已写回。 |
| K4 | 服务端只按 Komga book ID 重取文件位置，并将 Komga 库根映射到管理员配置的共享挂载根；拒绝越界路径、符号链接、非普通文件和不允许的书库。浏览器/API 不接受任意宿主路径；Komga 凭据与路径不回显到页面或日志。 |
| K5 | 保存先验证归档与打开时版本，再独立复制并校验私密完整原件备份；仅替换或新增 ZIP 根目录精确名 `ComicInfo.xml`，其他条目内容、顺序、可观察头信息和页面字节不变。隐藏非漫画扩展的临时文件写完并回读验证后才原子替换；失败、取消、空间不足或冲突均不损坏目标原件，草稿与备份可追查。 |
| K6 | 写回后对该 book 发起 Komga 单书 analyze；对于允许清空但导入器不会删除旧值的 book 字段，按白名单补充 PATCH 清空并回读。库未启用 ComicInfo 导入或目标字段被锁时，保存前阻止写回；首版不暗中解锁。分别报告文件已写、Komga 当前值一致及本次 analyze 的可验证程度；202、SSE、PATCH 后的相等值都不能单独证明导入完成。 |
| K7 | 文件替换、Komga 异步刷新和可选 PATCH 清空不是单个事务；页面分别呈现“文件已保存/无文件差异”“Komga 当前值一致/待同步”“本次分析已验证/无法证明”，支持同一操作 ID 的幂等保存请求、安全重试同步和显式恢复，不在部分完成时报告完全成功或盲目覆盖文件。 |
| K8 | 列表、详情、预览及备份操作受本项目单管理员会话保护；写入与重试同步受 CSRF/Origin 保护。备份、原 XML 与私密路径不经普通下载路由公开；操作记录和错误不泄漏凭据或私人内容。 |

## 验收标准

- [ ] K1、K2、K4、K8：管理员能从配置允许的 Komga 书库找到现有 CBZ，进入编辑页并看到从**文件**读出的当前元数据；匿名访问无法列出、查看或保存，跨库/路径逃逸和无共享挂载的写入被拒绝。
- [ ] K2、K3、K5：本次预览能区分 set、clear、保持不变；重新打开读到实际 XML 值，操作记录可显示当次明确清空（XML 缺项本身不能区分 clear 与从未填写）。代表性 CBZ 仅 ComicInfo 变化，其他 ZIP 条目的名称、中央目录相对顺序、哈希/CRC/长度、图片顺序、压缩方法、可观察头信息和 comment 保持不变；不要求物理字节偏移不变。备份可校验；未知/损坏/多份元数据、超限、写盘故障、取消及并发改动不造成静默损失。
- [ ] K6、K7：隔离 Komga 1.28.1 书库中，修改已有 ComicInfo 和首次新增 ComicInfo 经单书 analyze 后读取；改变的可导入非 clear 字段按 Komga 规范化规则回读一致。允许清空的字段经文件写回与必要的补充 PATCH 后显示为空；启用条码 ISBN 导入时清空 ISBN、其他不能清空的字段均被拒。锁定/导入关闭、超时与部分完成分别呈现，重复保存不二次覆写；XML 已无差异但 Komga 仍有旧值时仍执行同步，文件已提交但 Komga 未同步时可安全重试/恢复；仅 clear 而无因果证据时不声称本次分析已确认，不把系列聚合值当单本必然结果。
- [ ] K3、K8：未映射自定义字段、不能保真的 XML 内容及竞争元数据被准确说明；页面、API 和日志不输出 Komga 凭据、私密原件、绝对宿主路径或不必要的漫画正文。

## 范围外与依赖

首版不批量编辑、不改 PDF/EPUB/CBR、不重命名/移动或重排漫画页、不修改整组 series 元数据、不自动 AI 覆写、不直接访问任意宿主目录、不改既有下载任务快照。未映射自定义字段的跨文件可移植方案另行设计，不写自造 ComicInfo 扩展。`SeriesGroup`、`AlternateSeries`、`StoryArc` 等集合/阅读列表添加语义另行设计。

依赖管理员登录与元数据字段模型/ComicInfo 解析模块；需要可访问同一 CBZ 的受控共享挂载、Komga 管理员 API 凭据及启用的 ComicInfo 导入设置。真实 Komga/Kavita 兼容结果、文件系统外部写者竞态和系列聚合行为须在隔离环境中验证并记录限制。
