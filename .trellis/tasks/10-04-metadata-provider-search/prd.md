# 可配置书目来源检索与字段采用

## 目标

用户确认关键词及发送来源后，检索漫画书目、核对作品/版本，再逐字段补全当前元数据草稿；可管理每个来源的启停、优先级及所需认证，不把元数据限制在原七字段。

## 依赖与范围

- Batch 2；依赖 `10-04-metadata-contracts` 的版本化 metadata_document、字段注册表/来源证据/旧七字段适配，`10-04-source-settings-auth` 的单管理员登录、来源配置和凭据服务，`10-04-modern-ui-shell` 的页面插槽及草稿 revision 契约。
- 首批来源是 MangaBaka、MangaUpdates、Bangumi。只有固定 adapter 可被启用；来源设置扩展不等于用户可以上传可执行采集器。
- 已研究接口与有限中性书目命中；成人同人志、男同向漫画的真实覆盖率未验证。匿名无结果不能证明不存在，BL、年龄分级、同人/商业类型须分别保留。

## 需求

- P1 展示各来源能力、认证方式、启停和优先级；设置在共享来源配置保存。MangaBaka/MangaUpdates 支持匿名；Bangumi 支持匿名与可选服务端 access token，并提示成人结果受权限限制。没有需要认证的功能时不得强制伪造 API Key。
- P2 搜索由用户明确触发，展示即将发送的关键词与来源集合。只外发本次关键词/筛选条件，不发送截图、全部 OCR、频道文本、Telegram 凭据。关闭或未选来源不参与；优先级影响展示与调度，不自动决定采用字段。
- P3 有界并行查询选中的已启用来源，各源独立返回结果和错误。区分无结果、鉴权失败、权限不足/可见性受限、限流、超时、不可达、协议错误及主动取消；单源故障不清空其他候选或草稿。无法确认是否过滤时标记可见性未知，不虚报权限错误。
- P4 候选显示标题/别名、创作者角色、作品类型、系列/分卷关系、来源及来源 ID；选择候选后加载详情并按字段对照。不得自动选择第一条、混合同名作品或把总卷数当当前卷号。
- P5 详情生成独立 MetadataCandidate 建议，字段类型使用共享 registry，包括已注册的创作者、出版/标识/分级等字段及显式映射到已注册 custom.user.* 的扩展字段；未采用建议不进入 metadata_document，也不建立 manual_locked；未知信息保留为未知。旧七字段只是兼容投影。每个采用字段保存来源记录、检索时间和采用方式，保留署名/许可标识。
- P6 采用结果需要用户明确选择，支持只补空缺；已有用户修改、OCR/规则/AI 草稿不被迟到搜索或详情响应覆盖。改关键词、来源、草稿 revision 或页面离开后，旧响应不可直接采用。
- P7 所有 API、页面与凭据访问都受共享单管理员边界保护。凭据仅进入服务端受保护配置和 adapter 请求；页面仅显示是否已配置，不回读 token，不记录原始上游响应或敏感检索全文。
- P8 遵守来源条款、署名、限流和缓存条件；不做数据库镜像、批量抓取、自动跨源重试绕过拒绝，也不抓章节/封面资源。来自聚合器的上游字段不得统一标为聚合器自有许可。

## 独立验收

- [ ] P1：分别保存启停/优先级；匿名来源无凭据可检索，Bangumi 匿名/有 token 的 adapter 路径有隔离 fixture 验证，secret 不出现在浏览器 payload、日志和历史。
- [ ] P2/P3：一次确认请求仅调用所选已启用 adapter；三源中的一源 429、一源超时、一源成功时，成功候选保留且错误分别可见；无匹配与权限受限不混淆。
- [ ] P4/P5：合成同名、别名、作者角色、系列/单卷 fixture 可正确对照；至少一个超出旧七字段的内置字段和一个已注册 custom.user.* 扩展字段 连同 provenance 往返不丢失。
- [ ] P6：手改字段、切换关键词/来源、重挂载和乱序响应都不覆盖新草稿；用户逐字段采用后可通过 metadata-contracts 校验和旧七字段投影。
- [ ] P7/P8：未登录/CSRF 无效无法执行受保护操作；每源只向固定官方目的地发送自己的凭据；候选/导出可追溯署名与字段来源；缓存按用户权限和配置 revision 隔离。
- [ ] 不配置任何来源时，OCR、手工输入和原下载流程仍可用；无需真实成人资料即可完成上述自动化验收。
