# 单管理员登录与来源、AI 设置

状态：planning。父任务：`10-04-clipboard-ocr-tdl-ui`。本轮仅完成规划，未实施或部署。

## 目标与已确认范围

用户已明确选择内建单管理员登录。整个应用及敏感接口均需登录，来源凭据和可替换 AI 接口通过受保护的设置管理。没有多用户、角色权限、注册、邮件或密码找回邮件。

首选模型为 RackNerd 的 `minicpm5-2b-q4`，但当前仅服务器 loopback 可达；这不是产品已经可以访问的端点。本子任务不创建隧道、开放端口或调用远程模型。

## 需求

- 登录保护覆盖首页、任务、日志、历史、设置、上传与文件下载，以及后续 Telegram 登录/二维码/2FA/SSE、书目查询和 AI 调用。匿名只获得登录入口、必要静态资源、最少会话状态和无敏感信息的存活探针。
- 管理员初始密码由操作者通过本地私密环境或文件提供；没有默认、共享或页面公开的初始化密码。初始化缺失时应用拒绝开放业务功能。
- 服务端只保存密码哈希；会话可退出、过期及吊销，改密使旧会话失效。绝对期限 12 小时、空闲期限 30 分钟。状态变更需要会话和跨站请求防护，错误登录有有界限流且不透露密码或内部诊断。
- 来源分别展示启用状态、能力、所需认证和是否已配置凭据。匿名源不索要无用密码；已选适配器只获得其需要的 API key/bearer 等权限。未选需要 OAuth 的适配器时不引入 OAuth 流程。
- 来源支持整数优先级排序及该适配器允许的非秘密过滤/字段偏好；不支持的选项明确拒绝。优先级不代表自动采用或覆盖元数据，配置保存需检测并发版本冲突。
- 提供每来源独立的主动连接测试，按来源能力使用固定非敏感书目样例做只读验证；不发送当前 OCR、不修改来源数据、不回显秘密，并说明实际验证范围。来源能力目录由书目搜索模块负责。
- 凭据加密保存，主密钥在数据库及其备份之外受保护。读取配置只返回配置标记，不返回密钥、部分密钥、session 或可复用掩码。保留、替换、清除必须显式区分，空输入不得暗示其中一种。
- 公共来源目标由适配器固定；仅管理员能配置 AI Base URL，支持从 Go 服务网络可达的本地、自托管 HTTP(S) 服务。OCR、书目响应、模型响应和普通提取请求不能指定目的地、请求头或脚本。
- AI 设置包含开关、Base URL、可选凭据、准确模型 ID。配置保存后、进入已配置设置页时读取模型列表，提供手动刷新和模型 ID 输入。模型发现和固定无敏感样例的主动推理测试分别展示。
- 模型发现错误、空列表、401/403、429、不支持、超时及选中模型消失均可恢复，不自动切换模型。配置/凭据版本改变使旧发现和验证失效；旧响应不能覆盖新选择。
- 更换 AI 目标时不能向新目标转送旧密钥；重定向不携带凭据继续请求。日志、页面、错误、历史、漫画包及普通设置快照均不得包含秘密或 OCR 正文。
- 本子任务不重新定义元数据字段集合。用户已确认扩展超过现有七字段，推理测试消费 `metadata-contracts` 确认的版本化输出契约；历史七字段研究仅作为基线。
- 来源故障、无 AI 配置、AI 关闭或测试失败不阻塞本地 OCR、手工填写和下载，也不清空草稿。

## 验收标准

- [ ] 全路由矩阵证明：匿名/已退出/过期会话不能读取业务 HTML、htmx 片段、API、SSE、二维码、附件或修改状态；文件路径、方法别名与静态目录不能旁路。
- [ ] 无初始化秘密的全新库不能开放业务；并发启动只创建一个管理员，重启不自动覆盖密码。私密文件权限错误可明确失败但不显示文件内容。
- [ ] 正确登录轮换 session/CSRF；错误密码返回统一反馈并受限流；退出立即吊销当前会话；改密需要当前密码且使所有旧会话失效；绝对/空闲过期实际执行。
- [ ] 跨源请求、缺失/错误 CSRF、伪造代理头和登录 CSRF 被拒绝；合法 HTML 表单、htmx、fetch、上传及下载仍可使用。
- [ ] 数据库和其备份中无明文密码/API key；错误主密钥、密文篡改或缺失密钥不退回明文或匿名调用。配置 API 和日志的合成秘密检索无泄漏。
- [ ] 每来源独立保留/替换/清除成功，版本冲突返回 409，清除不能误删其他来源；匿名源不发送 Authorization，Bangumi 的 bearer 不发往其他来源。
- [ ] priority 的整数、范围和稳定排序可验证；允许的 filters/field_preferences 保存读回一致，不支持字段/取值被拒绝；设置与 provider-search 使用同一配置版本，不出现重复 revision。
- [ ] 逐来源测试只调用固定样例的允许读操作，反馈成功/不支持/无权限/限流/超时及验证范围；不发送页面 OCR，不更改启用状态、优先级和草稿，过期版本结果不覆盖新配置。
- [ ] 管理员可配置 loopback/内网模型；未登录者及 OCR 不能创建外部请求；固定公开来源不能用任意 URL 替换。
- [ ] 两个受控服务器证明：AI 目标改变不得 `keep` 旧凭据；任何 3xx 不跟随，第二台收不到原凭据；URL userinfo、fragment、query 和非 HTTP(S) 被拒绝。
- [ ] 模型列表成功/空/异常/限流/迟到均有中文状态；手工 ID 和缺失的已保存 ID 保留；列表获取不触发推理、不发送 OCR。
- [ ] 推理测试只发送固定无敏感样例且使用准确保存 ID；结果绑定配置/凭据/模型/契约版本，使用扩展元数据契约校验，失败不改用户草稿。
- [ ] 真实 MiniCPM 集成验收留给父任务建立的受控网络通路，记录可达性和固定样例结果；不把本地 mock 或既有 loopback 研究当作已完成产品集成。
- [ ] 中文登录和设置模块可通过键盘使用，密码不进入浏览器存储/历史快照，切页与退出清除输入、取消旧请求；构建产物同步更新。

## 依赖与排除

Batch 1 与 `metadata-contracts`、`modern-ui-shell` 并行规划/实现；正式 AI 输出测试接入等待元数据契约稳定。父任务统一 router、config、cmd、迁移及 shell 绑定。书目搜索适配、OCR 提取、Telegram 进程管理由其他子任务负责；这些模块消费本任务认证/配置服务。部署前必须完成 bootstrap 并保持既有无敏感健康探针，不提供临时匿名开关。
