# 跨模块集成与验收

## 目标与范围

将可扩展元数据、单管理员/来源配置、现代界面、多图 OCR/规则/AI、书目搜索、tdl 与 CBZ 合为可实际使用的流程。父任务的功能要求见 [PRD](../10-04-clipboard-ocr-tdl-ui/prd.md)；本任务从第一批开始承担共享文件集成，第三批完成最终验收，不将七个独立模块的单测等同于整套功能完成。

## 已确认约束

- 用户选择单管理员、同作品多图、本地 OCR、可配置 AI/规则及 MiniCPM5-2B Q4；来源及授权分别配置。
- 当前 Task Core 状态、lease/generation 和动作资格保持；旧 Telegraph/上传/历史可用。已有运行修复保留。
- 截图/OCR 默认页面内存，外发 AI/书目请求由用户主动触发；凭据不进入包、浏览器读回或日志。
- 父计划和七个模块提供技术契约；本任务拥有共享接线、迁移落号、构建及验证证据。
