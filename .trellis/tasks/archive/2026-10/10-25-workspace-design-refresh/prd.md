# Goal

Replace the rejected heavy PanelPort styling with a cohesive, restrained application interface informed by established product design. The user has authorized another frontend reconstruction and wants the result implemented and visually verified.

## Requirements

- R1: Refresh all three pages together: light navigation, compact sans-serif typography, restrained borders, clear form hierarchy and one accent color.
- R2: Preserve submit-only home, separate task history and Komga settings. Keep all seven optional metadata fields and per-submission library selection.
- R3: Preserve backend behavior, native JavaScript hooks, accessible labels, feedback and local assets. Do not add dependencies or a frontend build.
- R4: Preserve equal-height desktop columns, sticky inner navigation, shared content alignment and compact mobile navigation.
- R5: Review actual public design references and fresh screenshots, including populated task states and mobile forms.

## Acceptance

- The former navy sidebar, serif headings, decorative rules and oversized vertical spacing are replaced consistently across all pages.
- Existing functional, safe-rendering and responsive browser tests pass.
- Fresh desktop/mobile captures show aligned controls, visible primary actions and readable feedback without horizontal overflow.
- References, verification and limits are recorded in the task. Preview uses isolated temporary data and libraries.

## Out of scope

Backend/API/storage changes, production Komga operations, new controls or dashboard metrics, themes, dependency installation, deployment, push and merge.
