# OCR 与可配置 AI/规则的初步设计依据

> 范围更新：用户已明确元数据可扩展、来源及授权可配置；当前契约以 [父设计](../design.md) 为准。研究中的七字段实测仍只代表历史样例，不是扩展字段验收。

本文件记录规划建议，不代表已实现或已经验证 OCR 精度。用户已选择 OCR＋可配置 AI 接口/规则，并担心 R18 内容被外部服务拒绝或导致账号受限。

## 已确定的处理边界

- OCR 在浏览器本地完成，规则与手工填写可独立完成可扩展字段录入。下载由单独填写的来源链接决定。
- AI 仅接受用户主动发送的可编辑识别文字，默认不接受截图。原始 OCR 文本保留用于核对。
- AI 的拒绝、超时、限流、鉴权和格式错误仅影响本次建议；不删除草稿、不阻塞下载、不自动更换接口重发。
- 可配置接口不能保证第三方接受任何内容；是否接受、如何处理账号取决于提供方政策。可考虑连接自托管模型，仍须实测具体模型的行为和提取质量。
- 用户已确定首选 RackNerd 上的 MiniCPM5-2B Q4_K_M（`minicpm5-2b-q4`），使用 JSON Schema；该决定不取消可配置接口/模型选择，也不默认触发 AI 请求。当前 4096 上下文须同时容纳系统提示、字段契约、输入及输出预留，不能当作 4096 个汉字或 4096 个输入 token。
- 多张图属于同一作品，先逐图本地 OCR 和校对，再按用户顺序发送一份合并文字用于一份元数据候选。输入超预算时停止本次 AI 调用并提示缩减/选择文字；首版不自动切块生成后再拼接字段，不静默截断。详见 [多图契约](multi-image-ocr.md)。

## 接口的最小实现建议

用户已要求接口可配置且自动发现模型供选择。首版优先一个可替换的 OpenAI-compatible 接口，配置地址、可选密钥，并从该服务读取模型列表后选择模型；不固定 Grok 或某个域名。既能指向云端，也能指向用户指定的自托管服务；本地服务地址是相对于执行请求的 Go 服务/容器，不是相对于浏览器。具体兼容端点与响应样本仍需在实现前验证，不承诺所有标称兼容的产品均可工作。

设置与测试接口由服务端处理，避免浏览器持有服务密钥或依赖跨域策略。凭据写入后不回显；识别请求、错误日志、配置快照、元数据历史均不得带出密钥。测试连接采用固定的无敏感内容示例，不自动发送页面当前识别文字。

目标接口只能从受保护的设置中读取，不能由截图、模型响应或普通识别请求指定；关闭自动跳转，避免把 Authorization 带往其他主机。用户明确配置的内网模型需要支持，不能用一刀切禁止内网地址代替账号入口的访问控制。设置采用用户已确认的内置单管理员访问边界，详见父 design 和 source-settings-auth 子任务。

不引入供应商自动轮换、多代理或工具调用。输出键由当前字段注册表及本次所选提取字段生成（原七字段仅为兼容入口），经过类型、有效 UTF-8 字节长度与字段规范校验后成为候选；不直接写任务或历史。

## 模型发现与选择契约

- 用户确认地址与凭据后，以及打开已配置的 AI 设置时，受保护的设置接口由服务端访问规范化 Base URL 下的 `GET /models`。例如 Base URL 为 `https://model.example/v1` 时，目标是 `/v1/models`；不重复拼接 `/v1`，不把管理页面当模型 API。
- 解析常见 OpenAI-compatible `data[].id`，忽略格式不合法的项目，去重并提供搜索；保留真实 ID 用于调用，不把显示名称替换为模型 ID。上游返回有大小/数量上限和超时，标签通过普通文本呈现。
- 由用户选择并保存模型；模型列表加载与刷新不会自动选择第一项。能力信息不足时不能断言全部模型都支持文本或 JSON Schema。已知图片/视频用途与未知能力分开展示，选定模型仍须使用无敏感样例测试。
- 每个发现请求关联配置草稿版本；改地址、改凭据、发起新请求或卸载设置页时取消旧请求并忽略其迟到结果。原服务模型列表不得在新服务下继续作为有效列表显示。
- 获取列表和保存配置是独立动作；加载失败不破坏原有保存值。对于 `/models` 不支持、空列表或失败，显示原因并保留手工模型 ID 入口，不虚构可用列表。
- 已保存模型在刷新后缺失时保留选择并标为待核对，不自动更换，不把缺失等同于推理必然失败。手工模型与列表模型使用相同提取输出校验。
- 接口主机变更时不自动携带之前保存的密钥；由用户明确提供目标接口凭据。正常读取设置只返回是否已有密钥，编辑空值的保留/清除行为须显式区分，避免误删或误复用。
- 连接状态分成模型发现结果和所选模型的推理测试结果。仅列出模型不能宣布该模型可完成元数据提取；推理测试由用户主动触发，不以列表刷新触发推理。测试结果绑定地址、凭据版本和模型 ID，任一改变即失效；接口明确标记为仅图片/视频/embedding 的模型不用于文字提取。

## 规则的最小实现建议

从现有中文字段出发，提供可编辑标签别名与字段映射，例如“作品名/标题 → 漫画名”“简介/介绍 → 简介”，以及明确的 hashtag 分隔和多行续接规则。仅在结构明确时提取书名括号等模式，不据此推断作者、社团或翻译组的关系。

第一版优先这些有限模板，不直接执行用户脚本，也不构建通用可视化规则引擎。若需要任意正则，需先明确执行位置、限制和不可匹配行为，避免让一次粘贴阻塞页面。重复字段和冲突保留为待选候选，不覆盖已编辑字段。

## 验证重点

- AI 关闭或未配置时，完整录入与下载流程仍可用。
- 云端/自托管代表接口各用无敏感样例验证一次契约；拒绝与错误可通过可控测试服务验证。
- `/models` 成功、空列表、401/403、429、超时、不支持路由、非预期 JSON 和旧请求覆盖分别验证；配置保存后用受控服务断言提取请求使用所选模型 ID。
- 接口拒绝、非 JSON、额外字段、字段超长、过期请求和 prompt injection 文本均不影响已有编辑或下载目的地。
- 真实截图 OCR 的语言、清晰度、耗时和字段准确率尚未验证。图片识字与字段提取分别评价。
