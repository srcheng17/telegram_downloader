# 前端设计方向草案

> 范围更新：用户已明确元数据可扩展、来源及授权可配置；当前契约以 [父设计](../design.md) 为准。研究中的七字段实测仍只代表历史样例，不是扩展字段验收。

本文件是供最终设计收敛的建议，尚未创建产品 UI。沿用 Go templates、原生 JavaScript、htmx 与 Vite。

## 设计主体

这是个人漫画整理工作台，主要工作是从链接和截图生成带正确元数据的归档。新建任务应优先展示输入和核对工作区；统计数字放到任务页，避免占据录入首屏。

## 视觉与布局建议

- 画布 `#F3F6FA`，工作面 `#FFFFFF`，正文 `#182435`，次要正文 `#526175`，主操作蓝 `#2459C4`，边界 `#D4DDE8`。错误/警告另用明确文本和图标，不只用颜色。
- 中文采用系统字体 PingFang SC、Microsoft YaHei、sans-serif；正文 15–16px，页标题 24–28px，辅助文字不低于 13px。文件名、任务编号使用普通可读字体，长内容可换行或展开。
- 桌面使用窄导航加主工作区，主内容左对齐。录入区把“截图与识别文字”和“可扩展元数据表单”并排放置，方便逐项核对；顶部放下载来源，底部放开始任务与校验反馈。
- 截图可放大，截图列表支持连续粘贴、多选文件、顺序调整、移除和单图重试；每张展示识别状态。文本可逐图校对，也可查看按顺序合并的全文；规则和 AI 候选通过字段旁的标记及采用按钮呈现，避免用颜色作为唯一来源提示。
- 使用分区和留白表达层级；少量圆角用于输入、按钮和预览。动画仅用于用户触发的状态变化，并遵守 reduced-motion。

```text
┌───────────┬──────────────────────────────────────────────────┐
│ 新建任务  │ 新建下载                                         │
│ 任务      │ 来源：Telegram / Telegraph / 本地归档             │
│ Telegram  │ 链接或归档文件                                   │
│ 设置      ├─────────────────────┬────────────────────────────┤
│           │ 粘贴截图 / 图片预览 │ 漫画名、作者及扩展字段     │
│           │ 原始识别 / 编辑文字 │ 系列、序号                 │
│           │ 规则解析 / AI 辅助  │ 简介、标签、类型           │
│           │                     │ 最近填写 / 候选核对        │
│           ├─────────────────────┴────────────────────────────┤
│           │ 任务反馈                              开始下载   │
└───────────┴──────────────────────────────────────────────────┘
```

移动端改为单列；下载来源、截图、文本和字段按阅读顺序排列，提交动作不能遮挡当前焦点和错误提示。用户已确认一组图片对应同一作品；表单始终只有一份可扩展元数据。提供键盘可用的上移/下移按钮，不能仅依赖拖拽排序；处理细节见 [多图 OCR 契约](multi-image-ocr.md)。

## 页面职责

- **新建任务**：来源、截图识别、候选核对和提交。最近元数据按需打开，明确提示覆盖范围。
- **任务**：优先当前任务与可执行动作；详情展示进度、结果和必要错误。复用 Task Core 返回的动作资格，保留现有取消/重试/下载/Komga 能力。
- **Telegram**：账号状态、扫码连接与恢复；二维码过期、验证密码、验证中和授权成功各有明确状态。不展示命令行日志或 session。
- **设置**：下载行为、识别规则、可选 AI 接口。AI 区依次展示接口地址、密钥状态、自动获取的可搜索模型列表、刷新和所选模型测试；发现失败时显示手工模型 ID 入口。列表加载成功和推理测试成功分开反馈；未启用的 AI 不影响其他设置和工作区。

现有 `/logs` 地址可继续作为任务页兼容入口；不为改名破坏已有链接。截图/原始文字留在当前页内存，切页销毁时先保护未提交草稿，具体交互随最终设计确定。

## 设计自检

最有辨识度的部分应是截图和字段的并排核对体验，与本项目录入任务直接相关。新首页不沿用当前顶部四个统计卡片；没有添加营销横幅、装饰性渐变或无关封面墙。实施时必须用真实浏览器检验中文密度、截图缩放、键盘焦点、窄屏和长文件名，不能以 CSS 已写完作为视觉验收。
