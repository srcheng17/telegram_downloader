# 第一批交付与验证

本记录对应用户确认后的第一批：metadata-contracts、source-settings-auth、modern-ui-shell。三个独占模块并行实现，由 root 集成。分支 `creepy-kiwi`，保留原有未提交运行修复；未提交、推送、创建 PR、合并或部署生产。

## 已实现

- 版本化元数据文档与标准注册表，最多 64 个受约束自定义字段。保存字段来源、修订、人工保护及明确清空；false、0、空数组与缺省不同。新旧协议冲突明确拒绝。
- 任务与历史在同一事务保存文档，重试沿用提交快照。历史按任务身份区分，不会因七字段投影相同而误去重；未来版本或损坏的已存快照拒绝读取。
- 内置单管理员、会话/CSRF/同源保护、退出与改密吊销、私密文件初始化。原有页面、API、上传及文件下载统一受保护。新增本机密码恢复及密钥轮换命令。
- 采集源与 AI 配置的版本检查、凭据加密、保留/替换/清除；模型列表发现、手工模型 ID、固定无敏感样例测试。改变目标不能转送旧凭据，重定向不会继续携带秘密请求。
- 中文工作台、登录、设置、任务和 Telegram 挂载页；动态字段、历史提交/产物视图与逐项采用。新增可选字段后，旧历史中兼容字段可经显式预览采用；停用/不兼容字段保留只读预览。
- 上传 XHR、fetch 与 htmx 使用统一会话与 CSRF；失败导航保留草稿，退出、迟到请求和 BFCache 还原有清理与重新鉴权。

## 本批边界

OCR、多图合并识别、规则提取、真实公开书目搜索、tdl 登录/下载、扩展 ComicInfo 往返仍属后续批次，页面明确标为待接入。来源目录提供配置与准确的“不可用”测试结果，没有假装完成真实搜索。

当前 CBZ 仍使用既有七字段投影；扩展文档已保存。生产 worker 尚不生成 effective_metadata_document；有该快照时，历史可独立展示，测试已覆盖提交/产物隔离及 generation fencing。后续打包模块须补应用层派生文档校验再启用生产写入。

MiniCPM5-2B Q4 的真实服务网络接入尚未做产品验收；本批模型客户端使用受控 HTTP 服务测试，不代表真实模型效果或第三方授权已验证。未读取生产凭据或真实频道正文。
