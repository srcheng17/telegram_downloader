# 面向 AI 执行的全功能业务 CLI 与项目 Skill

状态：in_progress。用户已决定首版覆盖当前网页的**全部业务功能**，并交付供 AI 调用的项目本地 Skill。本任务是 `10-04-clipboard-ocr-tdl-ui` 的独立扩展子任务。

## 目标

管理员可通过 CLI 完成网页工作台的业务流程：从截图或书目生成可核对的元数据，提交 Telegraph 或本地压缩包任务，管理任务与全部设置，管理 tdl 账号连接，并编辑 Komga 存量 CBZ 的 ComicInfo。AI 使用项目 Skill 调用同一 CLI，服务端和网页读取同一状态；Skill 不成为新的权限入口。

## 已确认背景

- 网页当前有「新建任务 / 任务 / 作品库 / 设置」四个一级页面；设置分「下载、书目来源、AI 模型、字段、识别规则、连接、安全」七个 Tab。具体业务清单和源码锚点见[界面与接口盘点](research/current-cli-and-skill-surface.md)。
- 尚无通用业务 CLI。现有受保护 API 覆盖大量操作，但 `GET /api/tasks/{id}` 和下载设置 JSON API 等仍缺；`/api/metadata/patch` 只变更草稿，不持久化。
- 当前 OCR 由浏览器 File/Worker 与同源 Tesseract 资源执行；有限规则只在前端 JS 执行。CLI 不能以服务器识别图片替代“本地 OCR”，也不能把服务器的规则配置校验误称为规则执行。
- Telegram 消息新建下载来源已经移除；保留「设置 → 连接」中的 tdl 登录/验证及已有任务记录，CLI 不重新开放新建来源。
- 用户已决定 Komga 存量编辑首版**写回 CBZ 内 ComicInfo**；该能力由[Komga 子任务](../10-05-komga-metadata-management/prd.md)交付。CLI 命令依赖其文件安全、冲突与回读契约。

## 范围与要求

1. **CLI 基础与认证**：交付可独立安装/执行的业务命令（暂名 `mediactl`），具备帮助、版本、中文交互反馈、稳定 `--json` 结果和分层退出码。常规业务经受保护 HTTP API，使用管理员会话、精确 Origin、CSRF；仅向 HTTPS 或显式允许的 loopback HTTP 发送认证信息。密码/2FA/密钥只由用户在独立交互终端的隐藏 TTY 输入，不接受 argv、环境变量、JSONL 或 stdin 管道传入；凭据和会话不进入日志或 AI 可见结果，本地会话受文件权限保护。登录状态、登录、登出、修改密码均纳入 CLI 首版；AI Skill 遇到需密码、2FA、密钥或二维码的步骤，只指引用户在独立终端完成，再调用安全的 status/verify 结果。
2. **新建与元数据**：覆盖字段 schema、手工 set/clear、校验、历史候选选择、来源搜索/详情解析、规则候选、可选 AI 提取、逐字段预览/采用，以及 Telegraph 和压缩包任务提交。草稿、候选与持久化严格区分；提交时保留版本和锁定语义。重复 URL 先返回可机读确认态；明确 `force` 才新建重抓任务。上传保持现有限额及 init→attach 完整性。
3. **本地截图工作流**：支持同一作品多张图片的有序 OCR、语言选择、逐图校对/重试/删除/重排和明确采用候选。Mac 首版支持从剪贴板取图，文件输入支持多次 `--image`，非 Mac 环境可用文件输入并明确剪贴板不可用。沿用现有图片类型、数量、字节、像素和 OCR 资源限制；原图不发往业务服务器或外部 AI。OCR 原文与发送预览默认只留在同一作品的本机内存会话内，用户可从独立终端附着核对，AI 命令默认只取得安全摘要；原文不进入普通 JSON、日志、历史、归档或 Skill 示例。AI 提取须在该终端核对目标、模型、字段与文字预览后主动确认发送；仅传文字，不传图片。
4. **任务与文件**：覆盖概览、状态/关键词筛选、分页、单任务查询/等待、取消、重试、可用动作、文件检查/下载和复制到 Komga。CLI 以服务端动作资格为准，下载到指定本地路径须安全写入并回读；异步取消/复制结果不能仅凭请求成功视为最终状态。宿主绝对路径、完整私密错误日志不作为默认机器输出。
5. **七类设置与连接**：下载参数及成功动作模式、书目来源启用/授权/顺序/测试、AI 端点/模型发现/选择/测试、扩展字段、有限识别规则及本地预览、tdl 账号状态/扫码/两步验证/取消/验证、Komga 连接状态/凭据/测试、管理员密码都要有 CLI 等价操作。Komga 共享目录映射仍由部署配置限定，不能用 CLI 任意扩张。设置写入沿用版本/冲突校验；秘密只写不读，输入走安全通道。扫码由用户在交互终端完成，二维码及两步验证不进入 AI 可见 JSON。
6. **Komga 存量编辑**：CLI 可按书库/查询分页列出作品、按 book ID 读取和预览改动、手工修改并保存，并查看文件/Komga 分阶段结果、安全重试同步及显式恢复；保存遵循 Komga 子任务的 CBZ ComicInfo 回写、备份/原子替换、竞争检测和回读验证。不可编辑格式明确只读；不伪称项目扩展字段都可导出 ComicInfo。
7. **AI Skill**：随项目交付可发现的 `.agents/skills/media-workspace-cli/SKILL.md`（名称可在实现时定稿），仅描述实际已交付的命令、只读与写入边界、结构化错误、目标核对、敏感输入、显式外部请求与回读验证。默认 AI 输出只给不透明候选 ID、字段 key、状态/冲突等安全摘要，OCR/R18 正文由用户在独立终端核对；用户明确要求 AI 解读具体内容时才允许受控显式展示。Skill 不保存密码/会话，不自动扩大授权或通过 shell 拼接不可信文本。命令示例与同版本 CLI 自动校验。

## 范围外

纯视觉控件（侧栏折叠、Tab 切换、模态框动画）、绕过网页/API 鉴权直连业务数据库、Telegram 消息新建下载来源、自动批量覆盖/删除文件、默认持久保存 OCR 原文，以及在 Skill 中自行实现业务逻辑。当前网页没有的通用消息下载/批量扫描不因“全功能”新增。

## 验收标准

- [ ] **AC1** 新环境可运行 help/version；CLI 命令清单逐项映射三页业务能力，非交互 `--json` 成功/失败契约稳定，Skill 示例能对真实 CLI 执行。
- [ ] **AC2** 管理员完成登录、状态、登出、密码修改；未认证、错误 Origin/CSRF、过期会话都被拒绝；凭据/会话不出现在 argv、日志和普通 JSON。
- [ ] **AC3** 一组多截图（含 Mac 剪贴板入口）本机识别、重排、校对、规则预览/候选采用，失败图可单独重试；独立终端能附着到同一作品会话核对值并确认外发，AI 默认只读到安全摘要。资源超限和不支持的剪贴板平台给明确错误，图片不离开本机。AI 仅在用户核对并确认发送预览后请求已保存目标。
- [ ] **AC4** 使用手工、历史、书目、规则或 AI 的候选时，按字段预览并显式采用；定义/配置/文档版本变化时拒绝过时采用且保留原草稿。Telegraph 重复确认与 `force`、压缩包上传均可完成，网页回读到相同任务快照。
- [ ] **AC5** CLI 完成概览/筛选分页/单任务读取、取消/重试/等待、成功文件原子下载与复制；资格和最终状态与网页一致，失败及并发冲突不虚报成功。
- [ ] **AC6** 七个设置 Tab 的每项业务操作均有 CLI 等价命令；写入冲突保留本地输入并说明如何重载，来源/AI/Komga 连接测试不会泄漏密钥。tdl QR/2FA 在交互终端完成并以 account verify 核验。
- [ ] **AC7** Komga 子任务通过后，CLI 对同一存量 CBZ 完成列表、选择、预览、ComicInfo 回写、同步状态/重试及显式恢复；不可编辑格式与并发改动的反馈同网页一致。
- [ ] **AC8** 全新 AI 会话可发现本项目 Skill，并对代表性只读、用户授权写入及外部 AI 请求调用真实同版本命令；敏感登录/密钥/扫码由 Skill 引导用户在独立终端操作，AI 只读取后续安全状态。默认结果不回显 OCR/R18 正文、二维码、2FA、密码、来源密钥、宿主绝对路径；只有用户明确要求 AI 解读内容时才走受控显式展示。

## 依赖与验收边界

Komga CLI 命令的实现和 AC7 依赖 Komga 子任务先交付可用接口；计划包含该依赖，但本子任务不能以占位命令宣称“全部页面功能”完成。OCR/规则/登录等以本机或隔离环境的真实路径验收；mock 只证明局部契约，不证明实际 OCR 质量、tdl 授权或 Komga 扫描结果。
